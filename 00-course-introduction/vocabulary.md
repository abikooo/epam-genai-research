# GenAI vocabulary

## hallucination
When an AI model confidently states something completely false or made up, as if it were an actual fact. 
In my report: Chatbots, RAG, translation case   

## RAG
Instead of relying purely on memory, which can lead to guessing or making things up, the AI first searches a trusted DB or web documents for the right facts, and uses that info to make an accurate answer.
In my report: RAG

## LLM 
An AI model trained on massive amounts of data(text) to understand, generate and process human language. Like ChatGPT, Claude, Gemini, etc. 
In my report: Automated Test Generation

## Agent 
An AI system that can act autonomously by making decisions, using tools and taking action.
In my report: most use cases use this term, Code Generation, customer support, texttoSQL, workflow automation   

## Benchmark 
A set of tests or data used to measure and compare the performance, speed, or accuracy of different AI models.
In my report: TextToSQL and Workflow Automation

## Semantic Model 
A layer built on top of database tables and schemas that maps business terms and metrics (like "revenue" or "active customer") to actual columns, enabling tools to write correct SQL queries automatically.
In my report: TextToSQL and Data analysis

## Test Oracle
A mechanism; could be a human, script or baseline to determine whether a software test passed or failed by knowing the correct output.
In my report: Automated Test Generation

## Low-resource
Refers to languages, domains, or tasks with very limited available training data.    
In my report: translation and localization

## Code completion 
An AI or IDE feature that predicts and automatically or by choice types the next line of code. Basically an autofill.
In my report: Code generation.

## Neural Machine Translation
translating text between human languages with a neural network (NMT)
In my report: Translation and Localization

## Reinforcement Learning
A ML method where an agent learns to make decision by trial and error, earning rewards for good actions and penalties for bad ones. 
In my report: Automated Test Generation

## Brand Voice
The distincy personality, tone and style of a company uses across all its written and spoken communication
In my report: Marketing

## Translation Memory
a DB that stores previously translated phrases, sentences, or segments to reuse them in the future. 
In my report: Translation and Localization

## Glossary 
a list of specific terms, product names, and defined words to ensure consistent terminology.
In my report: Translation and Localization

## Field Experiment
a study conducted in a real-world setting rather than in a controlled laboratory environment
In my report: code generation

## Preregistered 
a practice when researchers officially file their study plan and analysis method before gathering data to prevent bias
In my report: marketing content generatoin

## Standard Error
a statistical metric that measures how much a sample mean is expected to vary from the true population mean.
In my report: Code Generation

## Unit Test
a piece of automated code written to test a single unit of code, isolated function or components of a software app.
in my report: automated test generation

## SQL Dialect 
a specific variant of the SQL query language adapted for a particular DB system (PostgreSQL, MySQL, etc.)
In my report: TextToSQL and data analysis

## Grounded
an AI response that is directly rooted in verified, provided factual sources rather than unverified memory
In my report: Enterprise search and document question answering (RAG)

## Context Window
the max amount of text(in tokens) an AI model can read and process in a single interaction window. 
In my report: not directly mentioned, but context-wise exists in most use cases

## Human in the Loop
a setup where human intervention, review or approval is built into an automated AI process.
In my report: not directly mentioned, but context-wise exists in most use cases

## Guardrails
safety rules, filters and boundaries set up around an AI system to prevent it from outputting toxic, illegal and unwanted/innapropriate content
In my report: not directly mentioned, but context-wise exists in most use cases
